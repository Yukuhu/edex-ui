# Security Policy

## Supported Versions

The latest commit on the `master` branch is the only supported version. There are no released binaries for nDEX-UI yet.

## Reporting a Vulnerability

Please report security vulnerabilities privately via the project's [GitHub Security Advisories](https://github.com/Yukuhu/edex-ui/security/advisories/new) page rather than opening a public issue. This lets us triage the report before any details become public.

If you don't have a GitHub account or the advisory form is unavailable, fall back to opening a regular issue but omit any reproduction steps or proof-of-concept — describe only the impact and we'll follow up to collect details out-of-band.
